Mathematical Primitives

State

The compact description carried forward because it decides what can happen next.

State Dynamics Value Function Policy Reachability

Action

The move the controller can legally choose.

Action / Control Input Optimal Control Problem Policy Reinforcement Learning

Dynamics

The rule that turns state plus action into the next state.

Dynamics Trajectory Optimization Model Predictive Control Model-Based RL

Cost

The future consequence accounting that lets candidate actions be compared.

Objective / Cost Function Value Function Bellman Recursion LQR

Constraint

A boundary that a solution must obey even when violation would lower cost.

Constraints Feasibility Recursive Feasibility Model Predictive Control

Value

A compressed price for the future from a state or action.

Value Function Dynamic Programming Value-Based RL

Policy

The rule that selects actions during execution.

Policy Policy Optimization Imitation Learning Reinforcement Learning

Uncertainty

The gap between what the controller expects and what may happen.

Stochastic Dynamic Programming Reachability Reinforcement Learning Model-Based RL
