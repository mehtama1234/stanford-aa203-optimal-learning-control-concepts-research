State

The information carried forward because it is enough to predict what the system can do next.

01 · the ordinary pressure

Why this idea has to exist

A controller cannot remember every past detail, but it needs the pieces of the present that determine future motion.

The tempting shortcut is simple: Store whatever measurements are available. But that shortcut breaks because some measurements are redundant, while missing velocity, battery charge, or contact mode can make the same position require different actions.

02 · the object

What the math keeps track of

The controller keeps track of a state vector or structured state description. This answers a practical question: ask what must be known now to predict the effect of the next action.

The operation is concrete: Update the state through the dynamics after each action.

03 · one concrete run

Work it through before naming the formula

Two cars can sit at the same point in a lane and need opposite controls. One is moving straight at 20 mph; the other is sliding sideways at 20 mph. Position alone hides the difference. Speed, heading, tire slip, and nearby cars are part of the state because they change what the next steering or braking command will do.

the actual math, one level deeper

A state is the smallest present-tense record that lets the model predict the next state from the next action. If two histories give the same state, the controller is claiming their future options are the same.

04 · boundary

Where the idea stops working

The chosen state must contain the information needed by the dynamics and cost.

If that boundary is crossed, the visible failure is this: a controller built on an incomplete state may take identical actions in situations that are physically different.

Recognize it in a new problem: Ask what must be known now to predict the effect of the next action.
