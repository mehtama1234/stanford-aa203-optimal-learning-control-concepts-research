Reward

The feedback signal that tells an RL agent which consequences are desirable.

01 · the ordinary pressure

Why this idea has to exist

An agent needs a scalar learning signal, but real tasks often have many values: safety, speed, smoothness, cost, and success.

The tempting shortcut is simple: Reward the easiest measurable outcome. But that shortcut breaks because the agent may maximize the measurement while violating the intended behavior.

02 · the object

What the math keeps track of

The controller keeps track of a reward function and return. This answers a practical question: ask what behavior the scalar feedback would encourage if exploited literally.

The operation is concrete: Accumulate reward over time and update behavior toward higher expected return.

03 · one concrete run

04 · boundary

Where the idea stops working

The reward must align with the real task and safety constraints.

If that boundary is crossed, the visible failure is this: reward hacking produces high score and bad behavior.
