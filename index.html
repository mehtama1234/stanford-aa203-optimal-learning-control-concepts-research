Course Throughline

Optimal and learning-based control studies how to choose actions over time when a system moves, constraints matter, and the future depends on earlier choices. The course starts with optimization and path methods, then moves through dynamic programming, reachability, MPC, imitation learning, reinforcement learning, and model-based RL.

Optimization

Choose actions by naming an objective, constraints, and a way to improve the candidate.

Dynamics

Respect that today's action changes tomorrow's state, so decisions are chained through time.

Value

Compress future consequences into a quantity that lets the next decision be compared.

Feasibility

Keep planned actions inside real constraints, especially when replanning with MPC.

Learning

Use data, demonstrations, or reward feedback when a hand-written model is incomplete.
