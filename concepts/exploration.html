Exploration

Trying actions to discover consequences the agent does not yet know.

01 · the ordinary pressure

Why this idea has to exist

An agent cannot improve only from familiar behavior if better actions have never been tested.

The tempting shortcut is simple: Always take the action that currently looks best. But that shortcut breaks because early estimates are wrong or incomplete, so greed locks in mediocre behavior.

02 · the object

What the math keeps track of

The controller keeps track of an exploration strategy or stochastic policy. This answers a practical question: ask what the learner must try before it can know which action is best.

The operation is concrete: Trade off exploiting known reward against collecting information from uncertain actions.

03 · one concrete run

Work it through before naming the formula

A robot that always repeats the first safe grasp it found may never learn a better grasp. A robot that explores wildly may drop objects or hit the shelf. Exploration is the controlled search for trials that teach the policy without wrecking the task.

the actual math, one level deeper

Exploration changes the action distribution to gather information. The tradeoff is between learning value and the cost or risk of trying uncertain actions.

04 · boundary

Where the idea stops working

Exploration must respect safety and data-collection cost.

If that boundary is crossed, the visible failure is this: unsafe exploration damages hardware or learns from unrepresentative trials.

Recognize it in a new problem: Ask what the learner must try before it can know which action is best.
