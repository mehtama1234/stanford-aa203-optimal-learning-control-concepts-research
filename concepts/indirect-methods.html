Indirect Methods

Solve an optimal-control problem by first deriving equations that an optimal trajectory must satisfy.

01 · the ordinary pressure

Why this idea has to exist

Instead of searching over all paths directly, use mathematical structure to reduce the search to conditions of optimality.

The tempting shortcut is simple: Discretize everything immediately and hand the whole problem to a numerical optimizer. But that shortcut breaks because direct search can be large and blind to the state and cost sensitivities already implied by the equations.

02 · the object

What the math keeps track of

The controller keeps track of necessary conditions such as state, costate, and stationarity equations. This answers a practical question: choose this lens when the analytic necessary conditions are central to the method.

The operation is concrete: Derive the boundary-value problem implied by optimality and solve those equations.

03 · read it with your hands

What to inspect first

Point to the physical record or mathematical object before naming the method. In this concept, that object is necessary conditions such as state, costate, and stationarity equations. Ask what a person could measure, command, update, price, or forbid in one small run.

Now apply one command or one update. Derive the boundary-value problem implied by optimality and solve those equations. After that operation, ask what changed in the next state, the path, the value, the constraint set, the policy, or the learned model. If nothing concrete changes, the explanation is still only a label.

The world check is the example: For a spacecraft transfer, the indirect method derives equations for both the state path and the shadow price of state errors. A reader should be able to replace that setup with another car, drone, rover, robot arm, or reward signal and keep the same control question alive.

04 · one concrete run

Work it through before naming the formula

Instead of giving a big nonlinear program to a solver, an indirect method first derives the equations an optimal path must obey. It is like finding the laws of the winning path before trying to compute the path itself.

the actual math, one level deeper

The method derives state equations, costate equations, boundary conditions, and stationarity conditions, then solves that boundary-value problem.

05 · boundary

Where the idea stops working

It depends on correct derivation and can be sensitive to boundary guesses.

If that boundary is crossed, the visible failure is this: the equations are hard to solve numerically or describe only a local candidate.

Recognize it in a new problem: Choose this lens when the analytic necessary conditions are central to the method.
