Hamiltonian for Optimal Control

A combined expression that packages immediate cost with how actions move the state into future cost.

01 · the ordinary pressure

Why this idea has to exist

An action must be judged both by what it costs now and by how it changes the state that future costs depend on.

The tempting shortcut is simple: Choose the action with the smallest immediate cost. But that shortcut breaks because the cheap action now can steer the state into an expensive region.

02 · the object

What the math keeps track of

The controller keeps track of the hamiltonian in an optimal-control necessary condition. This answers a practical question: use it when a local action must be priced by immediate and future state effects together.

The operation is concrete: Combine stage cost, dynamics, and costate sensitivity, then choose controls that satisfy the necessary condition.

Where the idea stops working

If that boundary is crossed, the visible failure is this: a trajectory satisfies local equations but is not the best or violates practical constraints.
