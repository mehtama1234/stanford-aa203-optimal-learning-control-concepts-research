Value-Based RL

Learn how good states or state-action pairs are, then choose actions using those learned values.

01 · the ordinary pressure

Why this idea has to exist

Instead of directly learning the action rule, the agent can learn a future-return scoreboard.

The tempting shortcut is simple: Estimate immediate reward only. But that shortcut breaks because the best action may have low immediate reward but lead to high future return.

02 · the object

What the math keeps track of

The controller keeps track of a state-value or action-value function. This answers a practical question: look for rl methods where action choice is derived from learned values.

The operation is concrete: Update value estimates from experience and act greedily or near-greedily with respect to them.

03 · one concrete run

Work it through before naming the formula

A game-playing agent may not know the best move directly, but it can learn which board states tend to lead to higher future return. It then picks actions by looking at the values of the states those actions create.

the actual math, one level deeper

Value-based RL learns V(x) or Q(x,u) from sampled rewards and transitions. The policy is obtained by choosing actions with high estimated value.

04 · boundary

Where the idea stops working

The value representation must generalize correctly across the visited state-action space.

If that boundary is crossed, the visible failure is this: function approximation error makes the agent overvalue bad actions.

Recognize it in a new problem: Look for RL methods where action choice is derived from learned values.
