Data → Equations → Control: One Machine

Three courses that look separate are three stages of one machine. Steve Brunton’s half turns measured data into a model and a state. Physics-informed ML and the DDPS seminar course learn, solve, and use the governing equations — the same move as Brunton’s equation discovery, and the supplier of fast, differentiable models. AA203 turns a model and state into the best control. The actions AA203 commands become the next round of data, and the loop closes.

Brunton — from data

Recover a model and a state from measurements: SINDy, DMD, Koopman, the Kalman filter, POD.

Physics-informed ML & DDPS — the law

Learn, solve, and use the governing equations: PINNs, symbolic regression, neural ODEs, operator learning, surrogates (PIML); differentiable simulation, hybrid twins, inverse problems (DDPS). Two sibling courses in the middle.

AA203 — to control

Given a model and state, compute the best action: dynamic programming, LQR, trajectory optimization, MPC.

And the loop closes. AA203’s controller acts, the world responds, and those responses are new measured data — which Brunton’s methods turn back into a model and physics-informed ML refines. Run that cycle continuously and you have adaptive, data-driven control, the meeting point model-based RL formalizes. Three courses, one loop.
