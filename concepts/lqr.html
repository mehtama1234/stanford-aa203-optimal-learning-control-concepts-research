LQR

A control method for linear dynamics and quadratic costs that produces a structured feedback law.

01 · the ordinary pressure

Why this idea has to exist

Near a nominal operating point, the controller needs fast feedback that trades state error against control effort.

The tempting shortcut is simple: Re-solve a full nonlinear trajectory problem at every tiny deviation. But that shortcut breaks because that is too slow when the system only needs local corrections.

02 · the object

What the math keeps track of

The controller keeps track of linear dynamics, quadratic cost, riccati recursion, and feedback gain. This answers a practical question: look for small deviations around a nominal trajectory with quadratic penalties.

The operation is concrete: Use quadratic value structure to compute how the control should respond to state error.

03 · one concrete run

Work it through before naming the formula

A drone hovering in still air does not need a full nonlinear planner for a two-centimeter drift. Near hover, the motion is almost linear and the penalty for being off-center is almost a bowl. LQR turns that local picture into a feedback rule: if the state error points this way, push back that way.

the actual math, one level deeper

Linear dynamics plus quadratic cost make the value function quadratic. The feedback gain comes from carrying that quadratic value backward through time.

04 · boundary

Where the idea stops working

The local linear-quadratic approximation must be valid for the deviations seen.

If that boundary is crossed, the visible failure is this: large nonlinear motion breaks the local model and the feedback becomes unsafe.

Recognize it in a new problem: Look for small deviations around a nominal trajectory with quadratic penalties.
