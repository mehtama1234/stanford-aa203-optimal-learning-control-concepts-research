Action / Control Input

The choice the controller is allowed to make at a particular moment.

Ordinary Problem

A planner needs to know which knobs it can turn: thrust, steering, torque, investment, braking, or a robot joint command.

Naive Approach

Treat every desired change as directly selectable.

Why it fails: A robot cannot choose its next position directly if motors only supply torques under limits.

Mathematical Object

A control input, action, or policy output.

Operation

Choose the input and feed it through the system dynamics.

Worked Example

A drone can command rotor thrust, not instant position; the position changes only through acceleration and velocity.

Boundary And Failure

Assumption Boundary

The action set must reflect actuator limits and legal moves.

Failure Mode

The plan asks for a move no actuator can produce.

Recognize It

Separate what you want the system to do from what command you can actually issue.
