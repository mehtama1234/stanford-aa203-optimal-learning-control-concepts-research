Value Function

A table or function that tells how much future cost remains from each state if decisions are made well.

Ordinary Problem

To choose now, the controller needs a compact price for the future after each possible next state.

Naive Approach

Re-solve the entire future plan from scratch for every possible action.

Why it fails: That repeats the same downstream reasoning and makes planning expensive.

Mathematical Object

A value function V or J.

Operation

Store or approximate the best future cost from each state.

Worked Example

In navigation, a cell near the goal has low value; a cell near a trap has high future cost even if it is nearby.

Boundary And Failure

Assumption Boundary

The value is meaningful only for the state, dynamics, objective, and policy assumptions used to compute it.

Failure Mode

A bad value estimate makes the controller prefer states that are actually costly later.

Recognize It

Look for the object that converts future planning into a number attached to the current state.
