Calculus of Variations

Optimization where the unknown is an entire curve or trajectory, not a single number.

01 · the ordinary pressure

Why this idea has to exist

A controller must choose a path through time, and changing one part of the path changes the total cost.

The tempting shortcut is simple: Optimize each point on the path independently. But that shortcut breaks because neighboring points are linked by dynamics and smoothness, so a path must be varied as a connected object.

02 · the object

What the math keeps track of

The controller keeps track of a functional that scores a whole curve. This answers a practical question: use this lens when the decision variable is a function of time.

The operation is concrete: Perturb the curve and require that no small admissible perturbation improves the cost.

03 · one concrete run

Work it through before naming the formula

A thrown ball path is not chosen at one point. The whole curve matters. Calculus of variations asks what happens to total cost if the entire path is nudged slightly, while endpoints or dynamics are respected.

the actual math, one level deeper

The object is a functional: it takes a whole curve and returns a number. The operation is to perturb the curve and set the first variation to zero for an optimal candidate.

04 · boundary

Where the idea stops working

The approach needs smooth variations and a meaningful path-level cost.

If that boundary is crossed, the visible failure is this: ignoring path coupling creates jerky or dynamically impossible motion.

Recognize it in a new problem: Use this lens when the decision variable is a function of time.
