Solutions

Setup solution

A strong answer separates measured state from desired outcome and names constraints before choosing an optimizer.

Method choice solution

Use direct transcription for a known one-shot motion plan, MPC for repeated constrained replanning, imitation when demonstrations are available, and RL when reward feedback is the main learning source.

Bellman solution

The correct move prices the next state by future value; the wrong move compares only immediate cost.

MPC feasibility solution

The weak plan is feasible now but not recursively feasible; a terminal set or longer horizon may be needed.

Reward solution

The reward omits comfort or safety, so the agent can score well by braking aggressively.

LQR solution

Local quadratic reasoning is credible near the nominal trajectory and risky after contact changes, saturation, or large nonlinear deviations.
