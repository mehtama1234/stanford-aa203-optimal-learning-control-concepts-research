Policy

A rule that maps what the agent knows about the current situation to an action.

01 · the ordinary pressure

Why this idea has to exist

The controller needs a repeatable decision rule, not a separate hand-picked action for every moment.

The tempting shortcut is simple: Store a fixed action sequence. But that shortcut breaks because disturbances and uncertainty mean the state may differ from the planned path.

02 · the object

What the math keeps track of

The controller keeps track of a deterministic or stochastic policy. This answers a practical question: look for the object that chooses actions during execution.

The operation is concrete: Given a state or observation, output an action or action distribution.

03 · one concrete run

the actual math, one level deeper

The mathematical object is a deterministic or stochastic policy. The operation is: Given a state or observation, output an action or action distribution. The boundary is: A policy can only react to information available in its input.

04 · boundary

Where the idea stops working

A policy can only react to information available in its input.

If that boundary is crossed, the visible failure is this: the policy cannot recover from unseen states or missing observations.
